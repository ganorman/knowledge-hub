# Organizar conocimiento sin duplicarlo

Plantilla genérica · GAN · 16 de octubre de 2026.

## Prompt

```text
Ayúdame a organizar estas notas sin crear un sistema complicado.

Objetivo: [qué necesito encontrar o reutilizar].
Notas: [pegar únicamente contenido autorizado para esta herramienta].

1. Haz un inventario completo de lo recibido.
2. Separa datos estables, procedimientos, proyectos, ideas y referencias.
3. Detecta duplicados y contradicciones. Propón una fuente principal por tema.
4. Propón el menor número de categorías que permita encontrarlo con claridad.
5. Para cada nota registra título, fuente, fecha disponible y estado de revisión.
6. Señala lo privado o sensible. No lo incluyas en una versión pública.
7. No crees carpetas vacías ni inventes datos para rellenar secciones.
8. Presenta los cambios antes de mover o eliminar originales.

Entrega: tabla de notas, organización propuesta y dudas pendientes.
```

## Uso

Una referencia a la fuente evita mantener dos versiones contradictorias. Una nota de trabajo puede ser útil sin estar lista para publicarse.
