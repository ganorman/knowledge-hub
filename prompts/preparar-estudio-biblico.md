# Preparar un estudio bíblico con fuentes

Plantilla genérica · GAN · 16 de octubre de 2026.

## Prompt

```text
Ayúdame a preparar un estudio bíblico para [audiencia], sobre [tema o pasaje].
Objetivo: [qué debe comprender o aplicar la audiencia].
Duración: [minutos]. Traducción bíblica: [versión].
Fuentes disponibles: [textos, notas o referencias autorizadas].

Primero propón un bosquejo con introducción, dos o tres puntos, aplicación y cierre.
Espera mi revisión antes de desarrollar cada sección.

Para cada punto:
- Identifica el pasaje y su contexto.
- Distingue cita literal, paráfrasis, interpretación y aplicación.
- Verifica las citas en la traducción indicada; si no tienes acceso, dilo.
- No presentes una analogía o una etimología discutida como hecho demostrado.
- Marca las ideas añadidas y las preguntas pendientes.

No inventes fechas, palabras originales, testimonios ni experiencias personales.
No generes archivos ni publiques el material hasta que lo solicite.
```

## Uso

La preparación del contenido y la revisión doctrinal siguen siendo tareas humanas. Esta plantilla organiza el trabajo y hace visibles sus fuentes.
