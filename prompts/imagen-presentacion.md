# Crear una imagen para una presentación

Plantilla genérica · GAN · 16 de octubre de 2026.

## Prompt

```text
Crea una imagen de apoyo para una presentación sobre [tema].
Escena: [descripción]. Idea que debe comunicar: [idea central].
Proporción: [16:9, 3:4 u otra].
Zona reservada para el título: [izquierda, derecha o superior].
Estilo: [realista, ilustración o fotografía conceptual].
Paleta: [colores autorizados].

Mantén la composición sencilla y un solo punto de interés.
Deja libre la zona reservada para texto; añadiré el título después.
No incluyas letras, logotipos, marcas de agua ni rostros identificables.
No uses nombres, ubicaciones o datos privados de un proyecto real.
Si la escena representa un hecho histórico, distingue la recreación artística
de lo documentado. No inventes detalles técnicos para aparentar precisión.

Antes de terminar, revisa que la imagen sea legible al tamaño de la diapositiva
y que el contraste permita añadir el título en la zona reservada.
```
